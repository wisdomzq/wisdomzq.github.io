Current Research

Multimodal Data Processing on Heterogeneous Systems

I am currently exploring efficient execution of multimodal data processing pipelines on heterogeneous architectures, with a particular focus on Apple Silicon's unified memory architecture. My research investigates CPU-GPU collaboration, resource contention, and adaptive execution strategies to improve end-to-end throughput.

DocDB: A Database for Unstructured Document Analysis

Zequn Li, Yuanhao Zhong, Chengliang Chai, Zhaoze Sun, Yuhao Deng, Ye Yuan, Guoren Wang, Lei Cao

PVLDB 2025Demo

Query unstructured documents with SQL-like operations. Two-level retrieval and document-specific execution plans reduce the amount of text and the number of calls sent to LLMs.

Paper Code DOI

CCL25-Eval Task 4 System Report: Macro-Pattern Prompting and Efficient Fine-tuning for Factivity Inference

Zequn Li, Yuanhao Zhong, Chengliang Chai

CCL 2025Oral

Inferring whether an event is factual from Chinese text. Macro-pattern prompting and efficient Qwen3-32B fine-tuning reach 94.01% and 92.61% accuracy in their respective tracks.

Paper PDF

Efficient Instruction-Tuning Data Extraction for Large Language Models

Project lead · Qiyan Program (启研计划)

Extract high-value QA pairs for LLM instruction tuning without scanning every document. Contrastive representations, adaptive sampling, and optimal-transport feedback guide where to extract next.

Beijing Natural Science Foundation · CNY 50,000 research grant
